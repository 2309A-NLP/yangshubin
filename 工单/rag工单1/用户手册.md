# RAG PDF 问答系统 — 用户操作手册

## 一、系统简介

本系统是一个基于PDF文档的智能问答系统，能够：
- 解析PDF文档（支持文字和表格）
- 理解用户问题（意图识别、消歧、关键词提取）
- 从文档中检索相关内容并生成准确回答
- 对比 RAG 模式与纯 LLM 模式的回答质量

## 二、快速开始

### 第一步：启动系统

打开终端，进入项目目录，执行：

```bash
python main.py web
```

看到以下提示表示启动成功：

```
启动 Web 界面...
* Running on http://0.0.0.0:5000
```

### 第二步：打开浏览器

在浏览器地址栏输入：

```
http://localhost:5000
```

即可看到问答界面。

## 三、功能操作指南

### 3.1 提问（RAG模式）

1. 在输入框中输入问题，例如：
   > 武汉兴图新科电子股份有限公司注册资本是多少？

2. 点击「发送」按钮或按回车键

3. 系统将：
   - 分析问题意图和关键词
   - 从PDF文档中检索相关内容
   - 基于文档生成回答

4. 回答下方会显示「参考来源」，标注答案来自文档的哪些段落

### 3.2 对比模式

勾选「对比模式」后提问，系统会同时返回：
- **RAG回答**：基于PDF文档检索后生成
- **纯LLM回答**：仅凭模型自身知识生成

方便对比两种模式的准确性和可靠性。

### 3.3 纯LLM模式

勾选「仅LLM」后提问，系统将跳过文档检索，直接用大模型回答。

适用于：测试模型自身知识、对比有无文档的区别。

## 四、命令行操作

除了Web界面，系统还支持命令行操作：

### 4.1 构建知识库

```bash
python main.py build
```

处理流程：PDF解析 → 文本切分 → 向量生成 → 存入Milvus

完成后会输出：
- PDF页数和字符数
- 切分的文本块数量
- 导出的数据文件位置

### 4.2 命令行问答

```bash
python main.py query
```

进入交互模式，直接输入问题即可获得回答。输入 `quit` 退出。

### 4.3 运行评估

```bash
python main.py eval
```

自动运行10个测试问题，对比RAG与纯LLM的回答质量，输出评估报告。

### 4.4 一键运行

```bash
python main.py all
```

先构建知识库，再自动启动Web界面。

## 五、常见问题

### Q1: 启动后页面打不开？

确认：
- 终端显示 `Running on http://0.0.0.0:5000`
- 浏览器访问的是 `http://localhost:5000`（不是 https）
- 防火墙没有拦截 5000 端口

### Q2: 回答说"根据提供的文档无法确认"？

说明检索到的文本块中没有包含答案信息。可能原因：
- PDF 文档中确实没有相关内容
- 问题表述不够明确，尝试换种方式提问
- 知识库未构建，先执行 `python main.py build`

### Q3: 响应很慢（超过10秒）？

- **首次请求**：系统需要加载 BGE-M3 模型（约10秒），后续请求会很快
- **Milvus 未启动**：检查 Docker 容器是否运行：`docker ps | grep milvus`
- **网络问题**：DeepSeek API 调用需要网络连接

### Q4: 如何更换PDF文档？

1. 将新的PDF文件放入项目目录
2. 修改 `config.py` 中的 `PDF_PATH` 指向新文件
3. 重新执行 `python main.py build`

### Q5: 如何查看已入库的数据？

```bash
python view_data.py
```

可查看PDF信息、文本块详情、Milvus中的向量数据。

## 六、数据导出说明

构建知识库后，`output/` 目录下会生成：

| 文件 | 内容 |
|------|------|
| 00_处理统计.txt | 处理耗时、文本块数量等统计信息 |
| 01_全文提取.txt | PDF完整文本内容 |
| 02_文本块总览.json | 所有文本块的ID、位置、预览 |
| 03_文本块明细.txt | 每个文本块的完整内容 |
| 构建日志.txt | 构建过程的详细日志 |
